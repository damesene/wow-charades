# Changelog

## 1.0.0

First public release.

- Resizable, scrollable menu with favorites (gold) and collapsible categories, search, and an All emotes view with an "animated only" filter.
- Minimap button with a quick menu: open Charades, settings, your favorites listed directly, and categories as submenus; right-click opens the window.
- Radial wheel: hold a key, point at an item and release. Favorites open right under the cursor; optional click-to-confirm and right-click to cancel.
- Actions can be emotes, any slash command, custom text emotes, spoken text or sequences with `/wait`.
- 55 built-in animated emotes in five categories (Social, Moods, Rest, Reactions, Signals), each with its own icon.
- 175 bundled icons plus the classic game icons, with search.
- In-game editor with drag and drop, restore defaults, per-character profiles, and export and import as readable JSON.
- Options split into the editor, General and Key Bindings pages; key bindings for the menu, the wheel and up to 10 favorites can be set right there.
